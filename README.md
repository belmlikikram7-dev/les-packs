# les-packs

Collection of landing pages and product packs.

## Structure

```text
les-packs/
├── landing-page-1/    # Pack Vinillia - Korean skincare routine & Sol de Janeiro gift
└── ...                # Future landing pages (landing-page-2, etc.)
```

## Projects

### 1. `landing-page-1`
- **Theme**: Pack Vinillia (Glass Skin routine, 6 Korean skincare products + Sol de Janeiro Beija Flor gift).
- **Framework**: Next.js 16 + React 19 + Tailwind CSS + TypeScript.
- **Languages**: Bilingual (Arabic RTL & French LTR).
- **Features**: Smooth scroll (Lenis), COD order form, phone verification (10 digits).
